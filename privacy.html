Privacy at a glance

FilzaPDF is designed as a desktop PDF reader and document utility. This policy describes its handling of documents and information. The statements below must reflect the features and behavior of the actual version you distribute.

01

Information We Collect

Use only if accurate: FilzaPDF does not intentionally collect personal information for the developer. The application does not require an account to use its local document-reading features.

If a future version introduces telemetry, diagnostics, analytics, account features, or other information collection, this policy must be updated to explain what is collected and why.

02

Your Documents and Files

Users choose which PDF files and other supported documents to open or process through FilzaPDF.

  • Users select the files they want to work with.
  • Documents may contain sensitive or personal information.
  • Users are responsible for choosing where files are saved, exported, or shared.

Do not assume every operation is local unless you have verified that the released application does not upload or transmit documents through any feature or external service.

03

Application Permissions

FilzaPDF is distributed as a Windows desktop application. Its permissions allow it to run as a desktop program. A permission to run desktop code does not, by itself, mean that personal information is collected.

Access to files and other device resources depends on the features used and the permissions granted by Windows and the user.

04

Network Communications

This section must describe any network activity in the distributed version of FilzaPDF. If the app connects to update servers, remote services, analytics providers, or other endpoints, document those connections here.

If the application has no network features, verify that behavior before stating that it operates entirely offline.

05

Third-Party Services

If FilzaPDF uses third-party libraries or services that transmit information, those services and their data practices should be identified here. Merely including a software library does not necessarily mean that it receives user information.

This policy must be revised if third-party analytics, advertising, crash reporting, or cloud processing is added.

06

Storage and Data Retention

Users should be informed about where the application stores preferences, recent-file information, temporary files, and exported documents if the application creates or maintains them.

Any information retained by an external service must have a clearly described retention and deletion process.

07

Data Security

Users should keep their operating systems up to date, protect access to their devices, and maintain backups of important documents. No software or method of electronic storage can guarantee absolute security.

08

Children's Privacy

FilzaPDF is a general-purpose desktop utility. Do not add claims about age restrictions or the handling of children's information unless they accurately reflect the product and applicable requirements.

09

Changes to This Policy

This policy may be updated when the application, its features, or applicable requirements change. The effective date at the top of this page should be updated whenever a revised policy is published.

Questions about privacy?

For support or questions about FilzaPDF, visit the project's GitHub repository. For privacy inquiries, please identify the relevant feature or data-handling question.
