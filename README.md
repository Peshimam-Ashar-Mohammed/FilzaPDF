# FilzaPDF

A fast, lightweight, privacy-first, open-source PDF reader.

## Status

Under active development.

## Goals

- Free and open source
- No account required
- No cloud dependency
- Local-first
- Minimal telemetry
- Fast startup
- Low memory usage
- Windows and Linux support

## Technology

- Java 21
- JavaFX
- Gradle
- Apache PDFBox
- JUnit 5


gradlew.bat build
gradlew.bat run
